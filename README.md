
# Zecpath AI

AI-powered recruitment and automated hiring platform.

## Project Structure

- data/ - Dataset management
- parsers/ - Resume and job parsing
- ats_engine/ - Applicant tracking
- screening_ai/ - Candidate screening
- interview_ai/ - Automated interviews
- scoring/ - Candidate evaluation
- utils/ - Shared utilities and logging
- tests/ - Unit testing
- logs/ - Application logs

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Pytest

## Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

pip install -r requirements.txt

4. Run tests:

pytest -v
